# ATHLORA  — SIH Coding Starter

ATHLORA is a Smart India Hackathon prototype based on the idea of an Anti-Sedentary Engine.

## Core Concept

ATHLORA does not wait for a student to decide to exercise.

It uses:

- Fitness level
- Available time
- Environment
- Equipment
- Recent activity

to generate a context-aware Move Mission.

## Core Loop

Assess → Find Opportunity → Move → Verify → Improve

## Features

- Context-aware onboarding
- Move Mission generation
- AI Fitness Baseline
- Fitness Passport
- Fitness Growth Index
- Browser camera
- MediaPipe Pose Landmarker
- Squat repetition detection
- AI movement verification
- XP rewards
- Consistency tracking
- Campus Challenge
- LocalStorage persistence
